   📦 BüfeOS'u Başkasına Nasıl Verirsiniz?
═══════════════════════════════════════════════════════

BüfeOS'u bir büfe sahibine vermek istiyorsunuz? Harika!
İşte adım adım yapmanız gerekenler:


═══════════════════════════════════════════════════════
   📋 YÖNTEM 1: USB İLE TESLİMAT (ÖNERİLEN)
═══════════════════════════════════════════════════════

Adım 1: BufeOS Klasörünü Kopyalayın
────────────────────────────────────
1. Bu klasörün tamamını (BufeOS/) USB belleğe kopyalayın
2. USB boyutu: Minimum 100 MB yeterli


Adım 2: Büfeciye Verin
───────────────────────
1. USB'yi büfeciye verin
2. Şunu söyleyin:

   "USB'deki BufeOS klasörünü bilgisayarına kopyala.
    Masaüstüne kopyalarsan daha kolay.
    Sonra README_HEMEN_OKU.txt dosyasını aç."


Adım 3: Telefon Desteği
────────────────────────
1. Büfeci kurulum yaparken telefonla yardımcı olun
2. DESTEK_BILGILERI.txt'deki telefon numarasını güncelleyin!


═══════════════════════════════════════════════════════
   💾 YÖNTEM 2: ZIP DOSYASI (EMAIL/WHATSAPP)
═══════════════════════════════════════════════════════

Adım 1: ZIP Oluşturun
──────────────────────
Windows:
1. BufeOS klasörüne sağ tıklayın
2. "Sıkıştırılmış (zip) klasöre gönder"
3. "BufeOS_v1.0.zip" adını verin

Linux/Mac:
zip -r BufeOS_v1.0.zip BufeOS/


Adım 2: Paylaşın
─────────────────
• Email: ZIP dosyasını ekleyin (boyut: ~2 MB)
• WhatsApp: Direkt gönderebilirsiniz
• Google Drive: Link paylaşın
• WeTransfer: Büyük dosyalar için


Adım 3: Talimat Gönderin
─────────────────────────
ZIP ile birlikte şu mesajı gönderin:

───────────────────────────────────────
📥 BüfeOS Kurulum Talimatları:

1. ZIP dosyasını indirin
2. Sağ tık → "Tümünü çıkart"
3. Masaüstüne çıkartın
4. "BufeOS" klasörünü açın
5. "README_HEMEN_OKU.txt" dosyasına
   çift tıklayın
6. Talimatları takip edin!

Sorun olursa arayın: [TELEFON]
───────────────────────────────────────


═══════════════════════════════════════════════════════
   🌐 YÖNTEM 3: GITHUB (TEKNİK KULLANICILAR)
═══════════════════════════════════════════════════════

Eğer büfeci biraz teknik bilgiye sahipse:

Adım 1: GitHub Link
────────────────────
git clone https://github.com/[KULLANICI]/KucukBufe.git


Adım 2: Kurulum
───────────────
cd KucukBufe
KURULUM.bat  (Windows)
./start.sh    (Linux/Mac)
