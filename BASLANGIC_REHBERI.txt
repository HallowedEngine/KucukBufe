═══════════════════════════════════════════════════════
   📦 İLK KURULUM (Sadece 1 Kere)
═══════════════════════════════════════════════════════

Adım 1: Python'u Kontrol Edin
─────────────────────────────
1. Windows tuşu + R basın
2. "cmd" yazın, Enter
3. Şu komutu yazın:

   python --version

4. Eğer "Python 3.x.x" yazısı çıkıyorsa → Adım 2'ye geçin
   Eğer hata veriyorsa → Python'u yükleyin:

   → https://www.python.org/downloads/
   → "Download Python 3.x" butonuna tıklayın
   → Kurulum sırasında "Add Python to PATH" kutucuğunu işaretleyin!
   → Kurulumu tamamlayın


Adım 2: Gerekli Programları Yükleyin
─────────────────────────────────────
1. Bu klasörde (BufeOS) sağ tık yapın
2. "Git Bash Here" veya "Komut İstemi Aç" seçin
3. Şu komutu kopyalayın ve yapıştırın:

   pip install -r requirements.txt

4. Enter'a basın
5. 2-3 dakika bekleyin (internet gerekli!)
6. "Successfully installed..." yazısı çıkana kadar bekleyin


Adım 3: İlk Başlatma
────────────────────
1. "BUFE_BASLAT.bat" dosyasına çift tıklayın
2. Siyah bir pencere açılacak - KAPATMAYIN!
3. Şu mesajları göreceksiniz:

   ========================================
      🏪 BüfeOS Başlatılıyor...
   ========================================

   📦 İlk kurulum tespit edildi!
   📊 Demo veri yükleniyor...
   ✅ 34 adet ürün eklendi!

   🌐 Sunucu başlatılıyor...
   INFO: Uvicorn running on http://0.0.0.0:8000

4. ✅ HAZIR! Artık kullanabilirsiniz.


Adım 4: Tarayıcıda Açın
───────────────────────
1. Google Chrome veya Edge'i açın
2. Adres çubuğuna şunu yazın:

   localhost:8000/templates/index.html

3. ⭐ Bu sayfayı favorilere ekleyin!
   (CTRL+D tuşlarına basın)

4. ✅ 3 kartlı ana paneli görüyorsunuz!


═══════════════════════════════════════════════════════
   🎯 HER GÜN KULLANIM
═══════════════════════════════════════════════════════

Sabah Rutini:
─────────────
1. "BUFE_BASLAT.bat" dosyasına çift tıklayın
2. Siyah pencere açılsın (KAPATMAYIN!)
3. Tarayıcınızda favori bağlantısından açın
4. "Az Kalanlar" kartına bakın
5. Sipariş vermeyi unutmayın!


Satış Yapma:
────────────
1. Üstte "Hızlı Satış" butonuna tıklayın
2. Ürüne dokunun veya barkod okutun
3. "Satışı Tamamla" butonuna basın
4. ✅ Bitti! (3 saniye!)


Gün Sonu:
─────────
1. "Bugünkü Satış" kartına bakın
2. Ne kadar kazandığınızı görün
3. Siyah pencereyi kapatın (CTRL+C veya X)
4. Bilgisayarı kapatabilirsiniz


═══════════════════════════════════════════════════════
   💾 ÖNEMLİ: YEDEKLEME
═══════════════════════════════════════════════════════

Haftada 1 kere şunu yapın:
──────────────────────────
1. "backend" klasörünü açın
2. "bufeos.db" dosyasını bulun
3. Sağ tık → Kopyala
4. USB belleğe veya başka bir yere yapıştırın
5. Adını değiştirin: bufeos_28112024.db (tarih ekleyin)

⚠️  Bilgisayar bozulursa bu dosyayı geri yüklersiniz!


═══════════════════════════════════════════════════════
   ❓ SORUN ÇÖZME
═══════════════════════════════════════════════════════

Sorun: "Sayfa açılmıyor"
────────────────────────
✅ Çözüm:
   1. Siyah pencere (BUFE_BASLAT.bat) açık mı?
   2. Açık değilse, çift tıklayın
   3. Doğru adresi yazdınız mı?
      → localhost:8000/templates/index.html


Sorun: "Python bulunamadı"
──────────────────────────
✅ Çözüm:
   1. Python'u yükleyin: https://www.python.org/downloads/
   2. Kurulum sırasında "Add Python to PATH" işaretleyin!
   3. Bilgisayarı yeniden başlatın


Sorun: "Port 8000 kullanımda"
─────────────────────────────
✅ Çözüm:
   1. Zaten başka bir BufeOS açık olabilir
   2. Tüm siyah pencereleri kapatın
   3. BUFE_BASLAT.bat'ı yeniden başlatın


Sorun: "Ürün ekleyemiyorum"
───────────────────────────
✅ Çözüm:
   1. BUFECI_KILAVUZU.md dosyasını açın
   2. "Ürünlerinizi Ekleyin" bölümünü okuyun
   3. Hala sorun varsa beni arayın!
